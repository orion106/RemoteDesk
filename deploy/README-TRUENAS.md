# Установка общей базы инвентаризации

В архиве находится готовый Linux-образ `remoteassist-inventory-1.1.tar`. Сертификаты, пароли, личный Excel и рабочая база в него не включены.

1. Создайте на TrueNAS SSD dataset для базы/фото и HDD dataset для резервных копий; предоставьте UID/GID 1654 доступ к этим каталогам.
2. Подготовьте производственный HTTPS-сертификат и начальный пароль владельца по инструкции `INVENTORY-SERVER.md`.
3. Загрузите образ на TrueNAS командой `docker load -i /полный/путь/remoteassist-inventory-1.1.tar`.
4. В Apps → Discover Apps → Install via YAML вставьте `deploy/truenas-inventory.yaml`. Замените имена пулов и при необходимости порт. Локальный образ используется с `pull_policy: never`.
5. В Windows-программе откройте «Инвентаризация», задайте `https://имя-nas:8443` и войдите начальной учётной записью `owner`.

Подробности установки, резервных копий и восстановления: `INVENTORY-SERVER.md`. Результаты проверок: `VALIDATION.md`. SHA-256 образа: `SHA256SUMS.txt`.

`remoteassist-inventory-source.tar.gz` содержит исходники сервера, контракты, тесты и рецепты сборки; для обычной установки готового образа распаковывать его не требуется.
