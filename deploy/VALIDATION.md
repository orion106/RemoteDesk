# Проверка поставки инвентаризации

Проверено в локальной Windows-среде и Docker Desktop с Linux-контейнерами:

- Сервер и общие контракты .NET 10 собираются без предупреждений.
- Версия 1.1: 270 проверок Windows-клиента и интерфейса, включая коридоры всех пяти этажей, диалог карточки, сохранение черновиков связей и номера телефона, группы картриджей и обе темы; 39 проверок Excel на тестовых данных.
- Версия 1.1: сервер проверяет сохранение телефонного номера, размещение в коридоре, связи компьютер–монитор, запрет циклов и историю снятия связи. Семь контейнерных проверок выполнялись с образом 1.1.
- Локальный Windows/Docker-стенд обновлён пользователем через `Update-LocalInventory.ps1`; после обновления проверены работа контейнера 1.1 и запуск приложения. Скрипт выполняет резервное копирование, проверку записей и сохраняет старый контейнер. Это вспомогательный сценарий конкретного локального стенда, а не универсальный установщик.
- 49 серверных проверок пройдены, включая реальный ASP.NET HTTP-сервер с двумя клиентами, откат замены картриджей, фото, завершённые сверки со снимком кабинета/этажа, самостоятельный файл резервной копии без WAL/SHM, восстановление и сохранение идентичности базы.
- `docker compose -f deploy/truenas-inventory.yaml config --quiet` проходит.
- Linux x64 publish выполнен отдельно; для запуска без контейнера нужен ASP.NET Core Runtime 10.
- Образ `remoteassist-inventory:1.1` собран из актуальной Linux-публикации через `deploy/inventory.prebuilt.Dockerfile` на официальном ASP.NET Core 10 runtime.
- 7 проверок реального Linux-контейнера пройдены: HTTPS и авторизация, UID/GID 1654 с readonly root, запись SQLite/фотографий, согласованная резервная копия, сохранение данных после перезапуска, чтение фото и восстановление базы/фото/TLS-конфигурации из readonly-копии.

Работа на настоящем TrueNAS не проверялась: адрес NAS, datasets и производственный сертификат задаются администратором при установке. Выполненные контейнерные проверки использовали отдельные временные каталоги и тестовый сертификат, не обращались к NAS и не содержат личных данных пользователя в образе.

В комплекте поставки есть `remoteassist-inventory-1.1.tar` для `docker load`, YAML Custom App и инструкция. Многостадийный `inventory.Dockerfile` сохранён для независимой сборки из исходников; `inventory.prebuilt.Dockerfile` позволяет упаковать чистую проверенную Linux-публикацию без скачивания SDK-образа.
